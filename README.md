# Vertical Shooter (S/W engineering proj 1)

화면 아래쪽 플레이어 비행기를 좌우로 움직이며 총알을 쏘아, 위에서 내려오는 적을 맞히는 종스크롤 슈팅 게임.

> 이 README 는 스타터에 들어 있던 것입니다. 제출 전에 아래 **[학생 작성]** 부분을 직접 채우세요.

## 실행 방법

- Python 3.10–3.13, pygame 2.x
  - Python 3.14 에서는 pygame 2.6.1 이 설치되지 않으니, 3.10–3.13 중 하나를 사용할 것.

```bash
pip install pygame
python main.py
```

## 조작

| 키 | 동작 |
|---|---|
| ← / → | 좌우 이동 |
| Space | 시작 화면에서 게임 시작 / 게임 중 총알 발사 |
| R | 게임 오버 후 다시 시작 |
| Esc | 종료 (시작 화면에서도) |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `main.py` | 게임 루프 — 입력 처리, 갱신, 그리기, 점수·생명·게임 오버 |

## 개발 방식

`AI_USAGE.md`에는 질문과 반영 내역만 한 줄씩 남으므로, 작업 과정은 여기에 따로 정리.

**기능마다 반복한 순서**
1. 스타터 코드 조사 — 구현 위치, 호출 흐름, 쓸 수 있는 상수 확인
2. 테크 스펙 작성 — 설계 결정마다 선택지와 트레이드오프를 정리하고 직접 선택
3. 구현 — 결정한 설계대로 코드 반영
4. 커밋 — 한 커밋에 한 가지 변경, 브랜치별로 `--no-ff` 머지
5. 문서 — 머지 후 main에서 `README.md`와 `AI_USAGE.md` 갱신

**역할 구분**
- 직접 한 것: 설계 결정과 선택, 커밋 단위와 메시지, 브랜치·머지·push
- AI(Claude Code)의 도움을 받은 것: 선택지와 개념 설명, 구현 코드

**기능별 설계 기록**
- F1 플레이어 이동 — 입력 해석·이동·경계 보정을 책임별 메서드로 분리, 경계는 이동 후 보정: [테크 스펙](https://paul1405dev-hub.github.io/2026-11-17-oss-proj1-f1-tech-spec/)
- F2 총알 발사 — 발사 입력은 `KEYDOWN`(한 번 누름에 한 발), 총알 생성과 그룹 등록은 분리, 화면 밖 제거는 `Bullet`이 담당: [테크 스펙](https://paul1405dev-hub.github.io/2026-11-17-oss-proj1-f2-tech-spec/)
